# Aesthetic directions

Starting seeds for step 2 of the build workflow. They exist because "be distinctive" is too vague to act on, and models told to be creative still converge on the same few choices.

How to use this file: derive a direction from the design brief, then borrow, mix, or invert from the seeds below. If you find yourself picking the same seed across projects, or the one that sounds most "tasteful", stop and pick differently. Every entry is a default if used mechanically.

Contents: Seeds, Font starting points, Color method, Variation rules.

## Seeds

Each seed: world, structure it lends the page, type feel, color logic.

- **Printed technical manual**: numbered sections, margin notes, tables as primary content, diagrams with callout lines. Mono or grotesque for labels, a sturdy text face. Black on warm gray with one signal color.
- **Field guide or specimen plate**: dense labeled illustrations, captions, taxonomy-style navigation. Small-caps captions, a readable serif text face. Muted naturals with one saturated marker color.
- **Transit or wayfinding system**: bold lines, station-style navigation, strict grid, high-contrast signage type. Flat saturated colors on neutral, color used as a code system.
- **Record sleeve or poster**: oversized type, asymmetry, one image doing real work, cropped elements. Display face with attitude, minimal body. Two or three flat colors, no gradients.
- **Terminal or lab notebook**: monospace, ruled structure, timestamps, output blocks as content. Mono throughout with one proportional face for prose. One phosphor-like accent on near-black or paper.
- **Newspaper or ledger**: columns, rules, dense but hierarchical, datelines. Text serif with a condensed headline face. Ink black, newsprint, one editorial red or blue.
- **Hardware spec sheet**: tables, units, tolerances, part numbers, exploded diagrams. Narrow grotesque and mono. Neutral base, safety-orange or similar single accent.
- **Hand-made and tactile**: visible grain, irregular shapes, hand-lettered accents, photography of real objects. A friendly irregular display face. Earthy palette with a deliberate off-note.
- **Brutalist and raw**: system-adjacent text, hard borders, no shadows, visible structure, unusual layout. Plain text face with one loud heading face. Two hard colors.
- **Playful and sticker-like**: thick outlines, offset shadows, bright flat fills, chunky shapes. Rounded or chunky display face. Bold primaries, but not violet.

## Font starting points

Free, widely available (Google Fonts, Fontshare, open source). Check licensing before shipping. Pair by contrast: a display face with strong character, a text face that stays out of the way.

- Display with character: Bricolage Grotesque, Instrument Serif, Familjen Grotesk, Unbounded, Fraunces, DM Serif Display, Archivo (in expanded or condensed widths), Syne, Big Shoulders Display, Rubik Mono One.
- Text: Source Serif 4, Literata, Newsreader, IBM Plex Sans, Schibsted Grotesk, Hanken Grotesk, Public Sans, Figtree, Atkinson Hyperlegible.
- Mono: JetBrains Mono, IBM Plex Mono, Geist Mono, DM Mono, Martian Mono.

Warnings from the research: Space Grotesk is already the "artsy" default, and Fraunces plus cream plus sage is the newer tasteful default. Use them only if the brief calls for them, and say why.

## Color method

1. Name the world's dominant material or signal (ink, rust, copper, hospital green, signage yellow) before choosing hex values.
2. One dominant hue carries about 60 percent of colored surface; one accent carries attention targets only.
3. Tint neutrals toward the dominant hue instead of using pure gray.
4. Check contrast (WCAG AA minimum for text; APCA if available) before settling.
5. If the result drifts toward violet, indigo or purple, ask whether the brief justifies it.

## Variation rules

- Alternate light and dark between projects; do not default to dark with glow.
- Vary layout skeletons: asymmetric two-column, editorial single column, table-led, poster-led, split screen.
- Vary density: some products deserve sparse, some deserve dense.
- When the user supplies a brand, references or screenshots, those override everything in this file.
